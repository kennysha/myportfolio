A Hand-Coded Portfolio Site Built with HTML, CSS & JavaScript

Timeline
2019
Live site
kennysha.github.io
Source
GitHub

I coded this website myself using HTML, CSS, and JavaScript, with media queries, focusing on accessibility and responsive design — using two media queries to adapt to tablet and desktop views, as well as flex and grid layouts as needed.

The main issue I struggled with was responsiveness: although the media queries worked when I resized my browser in Chrome, they failed to work properly on actual smaller devices, for both tablet and mobile views. After countless hours on this problem without a solution, I chose not to use it as my actual portfolio website — I still include it in my work, though, to show my hard work, experience and capability with web design, and the creativity I was able to bring to the project.

Another challenge was simply placing elements where I wanted them within the space, which is why I realized how important it is to keep the original HTML data structure as simple and semantic as possible.

What I enjoyed most about this project was the endless customizability of colors and fun animated graphical features — explore the live site below and hover over things to see what I mean.
